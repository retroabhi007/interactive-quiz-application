# Interactive Quiz Application

An interactive, responsive Computer Science & AI quiz web application developed for **Lecture 10** coursework at JECRC University by **Abhishek Singh**.

## Live Application
- **Live Demo**: [https://retroabhi007.github.io/interactive-quiz-application/](https://retroabhi007.github.io/interactive-quiz-application/)

## Project Overview
This project presents an interactive quiz testing core knowledge in modern software engineering, Large Language Models, code version control, testing strategies, and algorithmic complexity.

### Topics Covered in the Quiz:
1. **Large Language Models (LLMs)**: Next-token prediction fundamentals.
2. **Conventional Git Commits**: Structure and prefix conventions (e.g., `feat:`, `fix:`).
3. **Unit Testing & TDD**: Verification failure before bug resolution.
4. **Web Development Architecture**: Separation of concerns with dedicated CSS styling files.
5. **Time Complexity Analysis**: Nested loops and quadratic time ($O(n^2)$) growth.

## Key Features
- **Dynamic Question Rendering**: Iterates sequentially through question banks via DOM manipulation.
- **Instant Visual Feedback**: Color-coded feedback (emerald green for correct answers, soft red for incorrect options) with the correct answer revealed.
- **Score & Progress Tracking**: Real-time counter tracking current question index and points accumulated.
- **Summary & Performance Rating**: Calculates total score percentage and tailored feedback upon quiz completion.
- **Restart Mechanism**: Allows re-attempting the quiz with reset state.
- **Dark Gold Theme**: Sleek aesthetic with modern CSS variables, subtle radial gradients, and keyboard accessibility.
- **Fully Responsive**: Adapts seamlessly to smartphones, tablets, and desktop displays.

## Technologies Used
- **HTML5**: Semantic document structuring.
- **CSS3**: Custom properties, Flexbox, responsive typography, and pseudo-class states.
- **Vanilla JavaScript (ES6+)**: Event handling, DOM manipulation, state management, and timers.

## Local Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/retroabhi007/interactive-quiz-application.git
   ```
2. Open the folder:
   ```bash
   cd interactive-quiz-application
   ```
3. Open `index.html` in any modern web browser or serve with Live Server:
   ```bash
   npx serve .
   ```
